### Lessons Learned

**시행착오** (실패 → 해결)
- fix 가 skip 되면 merge-gate 이후 job 전부 skip(GitHub 기본 조건은 조상 skip 도 봄) — 리뷰 R3 · yaml 테스트 · run_local 모두 통과, 실 run(PR #3)에서만 드러남 → `4-loop-chainfix` 로 후손 job 에 명시적 `if`
- 빌드가 깨지면 `loop-junit` upload `error` 로 test job 실패 → 게이트가 판정 불가를 판정 못 함(PR #10) · 게이트 BLOCK 시 계약 JSON upload 건너뜀(PR #6) → `5-loop-evidence`
- Git Bash `cmd //c "x.cmd"` 상대 경로는 「인식할 수 없는 명령」 — exit 0 처럼 보임 → 전체 경로 · PowerShell(메모리 기록)
- git 자격 증명이 다른 계정(sunsook)으로 잡혀 새 저장소 push 실패 → 저장소 로컬 `credential.helper=!gh auth git-credential`
- 측정 기록 끝 시각을 추정으로 적어 미래 시각이 3회 들어감 → `date` 출력만 사용
- 시나리오 브랜치 L3b 를 L3 위에서 분기 → L3b 머지 때 게이트가 막은 L3 도 merged 처리(게이트는 PR 단위라는 관찰로 전환)

**발견한 패턴** (재사용 가능)
- 루프 설계 = 게이트를 되돌리기 어려운 동작 바로 앞에 · test 는 판정하지 않고 분류만 · 기준 목록은 base 판(PR 이 채점 기준을 못 고침)
- 로컬 모델(run_local · yaml 구조 테스트)은 플랫폼 실행 규칙(skip 전파 · step 기본 조건)을 모델링하지 못한다 — 실 run 1회가 유일한 검출 수단. 그래서 무게이트 전체 루프를 먼저 실 GitHub 에서 돌리는 순서가 맞았다
- runner 가 읽는 코드는 detached worktree(`loop-home`)로 고정 → execute.py 실행과 E2E 를 겹쳐 돌려도 안전
- 같은 PR 의 GITHUB_TOKEN push 뒤 bot run 6건은 모두 job 0개(failure 3 · action_required 3) — 무한 루프 없음
- Free private 저장소 branch protection · ruleset 은 403 — 게이트는 workflow 안에서만
